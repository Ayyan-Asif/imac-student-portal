ABOUT THE PROJECT

Built for the IMAC community.

IMAC Portal is a Web Technology project concept for the Institute of Machine Learning, Artificial Intelligence and Cyber Security at UET Lahore.

IMAC
UET LAHORE

Our mission

The mission of this demo is to bring academic information, learning resources and student interaction into one simple platform. Instead of searching through scattered messages and links, students can find their timetable, lecture resources, events and community conversations from one portal.

Why it was made

This project demonstrates multi-page navigation, responsive UI, Tailwind CSS, JavaScript interactivity, form validation, local browser storage and a simulated developer/admin workflow.

Future version

A production version could use a real backend with authentication, MySQL/PostgreSQL, role-based permissions, secure password hashing and YouTube API integration.
